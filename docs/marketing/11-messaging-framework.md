# PetVue — Messaging Framework

> *Marketing gold. This is the single source of truth for how we talk about PetVue to every audience.*

## Universal Messaging Hierarchy

Every message should follow this pattern:

```
PROBLEM → SOLUTION → OUTCOME → PROOF
```

## Messaging Do's and Don'ts

### ✅ Do
- Lead with the pet, not the technology
- Emphasize peace of mind and clarity
- Be transparent about AI limitations
- Use plain language (no jargon)
- Show real scan results (with consent)
- Always include the medical disclaimer in health-related content

### ❌ Don't
- Claim PetVue replaces veterinarians
- Guarantee accuracy or diagnosis
- Use fear-based messaging ("Your pet might be DYING")
- Overstate AI capabilities
- Show stock pet photos (use real app screenshots)
- Ignore the disclaimer
